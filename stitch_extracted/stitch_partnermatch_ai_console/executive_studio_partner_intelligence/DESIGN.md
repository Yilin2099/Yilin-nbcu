## Brand & Style

This design system serves enterprise brand partnership directors, studio marketing executives, and media strategists navigating high-stakes film co-branding campaigns. The brand personality balances executive studio gravitas with forward-leaning AI intelligence: authoritative, analytical, discreetly cinematic, and frictionless.

The aesthetic blends **Modern Corporate Enterprise** with **Subtle Studio Glass**:
- Deep, prestige midnight navy backgrounds and clean architectural frames anchor the UI in studio legacy and operational discipline.
- Precision typographic hierarchy and crisp metadata ribbons evoke institutional deal sheets, production slates, and box-office intelligence dashboards.
- Micro-interactions are razor-sharp and tactile, reinforcing trust and speed during live partnership pitch builds and rights-matching workflows.

## Colors

The palette establishes an executive entertainment suite anchored in deep midnight hues, accented by Peacock-inspired dynamic spectral tones dialed to executive-grade saturation:

- **Primary (`#4F6BFF` - Electric Royal Indigo)**: Directs primary user intent, match confidence highlights, active film slate selections, and key conversion paths.
- **Secondary (`#00C2A8` - Studio Emerald / Cyan)**: Signals verified affinity scores, positive brand sentiment, confirmed talent clears, and financial uplift metrics.
- **Tertiary (`#E29547` - Studio Amber / Gold)**: Highlights exclusive windows, pending agency rights, contract flags, and tier-1 partner opportunities.
- **Neutral Base (`#0E131F` - Deep Midnight Slate)**: Anchors workspace canvases and navigation sidebars, providing cinematic contrast without true-black fatigue.

### Surface System
- **Canvas Base**: `#090C15`
- **Surface Elevation 1 (Cards, Tables)**: `#131926`
- **Surface Elevation 2 (Modals, Overlays, Flyouts)**: `#1B2335`
- **Surface Border Default**: `#242F45`
- **Surface Border Subtle**: `#1B2436`
- **Text High Contrast**: `#F0F4FC`
- **Text Muted / Data Labels**: `#8C9BB5`

## Typography

The type scale integrates technical rigor with editorial authority:
- **Headline Font (`Space Grotesk`)**: Technical yet expressive geometry reminiscent of production slates, projection frames, and modern analytics software.
- **Body Font (`Hanken Grotesk`)**: Ultra-refined grotesque typeface ensuring fatigue-free readability across complex negotiation dossiers, audience demo matrices, and campaign decks.
- **Label / Data Font (`JetBrains Mono`)**: Strict tabular alignment for AI affinity scores, demographic indices, budget clearances, and theatrical window dates.

Numerical telemetry must always set `font-variant-numeric: tabular-nums` to maintain vertical metric alignment across comparison columns.

## Layout & Spacing

The workspace uses a dense, high-utility **12-column fluid grid** designed for 1440px+ enterprise displays, with responsive degradation down to single-column workflows for tablet walk-throughs:

- **Desktop (1280px+)**: 12-column grid, `margin-lg` (2.5rem) exterior boundaries, `gutter-lg` (1.75rem). Persistent navigation rail (72px collapsed / 240px expanded) paired with dynamic double-pane inspectors (60/40 split for match matrices).
- **Tablet (768px - 1279px)**: 8-column layout, `margin-md` (1.5rem), `gutter` (1.25rem). Secondary panel collapses into an expandable drawer.
- **Mobile (< 768px)**: 4-column layout, `margin` (1rem), `gutter` (1rem). Grid items stack vertically; horizontal metric bands become swipeable snap-scroll carousels.

Vertical rhythm adheres to a strict 4px/8px modular cadence. Content blocks rely on internal padding to establish hierarchy without redundant dividers.

## Elevation & Depth

Visual depth is achieved through **low-contrast architectural outlines and tonal layers** rather than heavy blurred dropshadows, ensuring data readability in dark mode:

- **Base Layer (Level 0)**: `#090C15` background with subtle micro-dot grid alignment overlays (1px dots spaced at 24px, 4% opacity).
- **Surface Layer (Level 1)**: `#131926` background, surrounded by a 1px solid border (`#242F45`). No shadow. Used for default metric panels and film slate cards.
- **Elevated Interactive Layer (Level 2)**: `#1B2335` background, 1px border (`#344362`), cast with an ambient indigo-tinted shadow: `0 8px 24px -4px rgba(79, 107, 255, 0.12)`. Applied to active partner match comparisons, dropdown lists, and hover states.
- **Modal / Floating Drawer Layer (Level 3)**: `#1E283D` with a subtle inner top highlight (`inset 0 1px 0 0 rgba(255, 255, 255, 0.08)`) and an extended grounding shadow: `0 24px 48px -12px rgba(3, 6, 12, 0.65)`.

## Shapes

The design system employs a **Soft Architectural (`1`)** shape language:
- Standard structural surfaces (cards, table modules, input zones) carry a refined `0.25rem` (4px) or `0.5rem` (8px) radius, conveying institutional solidity and precision.
- Interactive indicators, status pills, and partner category chips utilize full circular/capsule curves (`9999px`) to create high-contrast geometric rhythm against rectangular data grids.

## Components

### Buttons
- **Primary**: Solid Royal Indigo (`#4F6BFF`) fill, high-contrast white text, `label-ui` typography, 8px corner radius. Subtle inner top border (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`). Hover transitions to `#3D59E8`.
- **Secondary / Studio Outline**: 1px border (`#344362`), transparent background, cool white text (`#F0F4FC`). On hover: background shifts to `rgba(79, 107, 255, 0.08)` and border illuminates to `#4F6BFF`.
- **Ghost Action**: Monospaced utility action (`label-code-sm`), no border, muted text (`#8C9BB5`), underlines or shifts to high-contrast white on hover.

### Chips & Status Pills
- **Match Score Indicator**: Monospaced capsule (`JetBrains Mono`, 11px), 9999px radius, 4px vertical / 10px horizontal padding.
  - *High Match (85%+)*: Background `rgba(0, 194, 168, 0.12)`, border `1px solid rgba(0, 194, 168, 0.35)`, text `#00E5C6`.
  - *Opportunity (60-84%)*: Background `rgba(79, 107, 255, 0.12)`, border `1px solid rgba(79, 107, 255, 0.35)`, text `#8FA2FF`.
  - *Watch / Conflict*: Background `rgba(226, 149, 71, 0.12)`, border `1px solid rgba(226, 149, 71, 0.35)`, text `#F5AC63`.
- **Category Filter Chips**: Dark pill, 1px border (`#242F45`). Active state turns primary indigo with a high-contrast dot indicator.

### Input Fields
- Dark inset surface (`#0D121D`), 1px border (`#242F45`), 8px radius, height 40px.
- Typography: `body-md` for user entry; `label-code-sm` for field descriptor labels resting above the frame.
- Active focus state: border shifts to `#4F6BFF` with an outer glow `0 0 0 3px rgba(79, 107, 255, 0.2)`.

### Cards & Slate Containers
- Structured multi-tier modules: Top banner features IP metadata (theatrical release quarter, MPAA rating, target demo).
- Body section presents the primary AI compatibility metric (large tabular figure) accompanied by an inline sparkline or demographic overlap gauge.
- Card footer contains deal status, exclusivity tags, and secondary action triggers.

### Checkboxes & Segmented Selectors
- Checkboxes: 16x16px square with 3px radius, 1px border (`#344362`). Checked state fills with `#4F6BFF` and displays a crisp white check vector.
- Segmented Slate Switchers: Inset capsule tray (`#0A0E17`) containing sliding tab controls with 4px radius and high-contrast active state pill indicators.

### Metric KPI Tiles (Domain-Specific)
- Compact data blocks featuring `label-code-sm` uppercase titles, `headline-lg` tabular numerical values, and micro color-coded deltas (e.g., `+18.4% Brand Recall Lift`) embedded directly in the top right corner.
